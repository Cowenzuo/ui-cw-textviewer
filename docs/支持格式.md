# 支持的文本格式

本文档与代码同步维护：以 `src/client/TextViewer.tsx` 的 `EXT_LANGS` /
`BASENAME_LANGS` 注册表为**唯一事实来源**，增删格式时同步更新本文档。

## 概览

| 渲染方式 | 识别项 | 说明 |
|---|---|---|
| Markdown 渲染 | 3 个扩展名 | react-markdown + GFM（标题/表格/任务列表/删除线/自动链接） |
| 代码高亮 | 55 个扩展名 + 2 个文件名 | Shiki（TextMate 语法，VS Code 同款着色）+ CSS 行号 |
| 纯文本 | 其余一切 | 不换行横向滚动；host 端 NUL 嗅探判定为文本即可显示 |

> 只要文件**不是二进制**（首块 8KB 无 NUL），任意扩展名都能查看——未知
> 扩展名自动落到纯文本渲染。二进制文件显示"暂不支持预览"提示。

## 一、Markdown 渲染（GFM）

## 三、纯文本（兜底）

- `.txt`、`.csv` 及所有未在上表出现的扩展名
- 只要 host 端编码探测成功（BOM → UTF-8 → GBK）且非二进制，即可查看
- 渲染为等宽纯文本：不换行、横向滚动，保持文件行结构

## 如何扩展新格式

1. `src/client/TextViewer.tsx` → `EXT_LANGS` 加一行（扩展名 → Shiki 语言 id）
2. `src/client/renderer.tsx` → 从 `@shikijs/langs/<语言>` 导入语法并加入
   `createHighlighterCore` 的 `langs` 数组（数组型导出需 `.flat()`）
3. 若文件名为特殊形式（如 `Dockerfile`），加入 `BASENAME_LANGS`
4. 同步更新本文档
